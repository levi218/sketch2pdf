# sketch2pdf

Convert Sketch (`.sketch`) files to PDF, rendered with Skia.

## Layout

- `sketch2pdf/` — library
- `sketch2pdf-cli/` — `sketch2pdf` command-line tool
- `tools/report.py` — builds a visual comparison report into `report/`

## Build

```bash
cargo build --release
```
